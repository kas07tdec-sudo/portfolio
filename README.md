# 🚀 Keval Shah — Personal Developer Portfolio

A modern, responsive, and performance-optimized personal developer portfolio built with pure HTML5, CSS3, and JavaScript (ES6+). This portfolio highlights my engineering projects, interactive web applications, data analytics dashboards, open-source contributions, and technical certifications.

---

## 🌐 Live Demo & Deployment

✨ **Live Portfolio:** [https://keval-shah-portfolio.netlify.app/](https://keval-shah-portfolio.netlify.app/)

---

## 🌟 Key Features

- **🎨 Light / Dark Theme Toggle:** Seamless switching with persistent theme preference stored in `localStorage`.
- **📱 Fully Responsive Design:** Fluid layouts optimized across mobile, tablet, and desktop screens.
- **⚡ Fast & Lightweight:** Zero framework dependencies—built using modern CSS variables and native vanilla JavaScript.
- **🔍 Filterable Projects Grid:** Client-side real-time project filtering by category (AI / ML, Web Applications).
- **🖼️ Interactive Dashboards Gallery:** Carousel slider displaying analytical Power BI dashboard models.
- **📊 GitHub Profile & Open-Source Section:** Dedicated showcase detailing public repositories, contribution activity, and tech stack focus.
- **🖼️ Technical Overview Modals:** Interactive popups delivering technical architecture overviews, tech stacks, and live links.
- **📜 Standardized Certifications Grid:** Symmetrical card layout highlighting technical credentials and simulation completions.

---

## 🛠️ Tech Stack & Architecture

- **Markup & Structure:** HTML5 (Semantic elements, Accessibility standard attributes)
- **Styling & Layout:** Modern CSS3 (CSS Grid, Flexbox, Custom Properties/Variables, Keyframe Animations)
- **Dynamic Logic:** JavaScript ES6+ (DOM Manipulation, Event Delegation, LocalStorage API, IntersectionObserver API)
- **Icons & Typography:** Font Awesome 6.7.2, Space Grotesk & Inter (Google Fonts)
- **Deployment & Hosting:** Netlify (Continuous Deployment)
