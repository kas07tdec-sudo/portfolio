# 🚀 Keval Shah — Personal Developer Portfolio

A modern, responsive, and performance-optimized personal developer portfolio built with pure HTML5, CSS3, and modern JavaScript (ES6+). This portfolio highlights my engineering projects, interactive web applications, data analytics dashboards, open-source contributions, and technical certifications.

## 📸 Key Features

- **🎨 Light / Dark Theme Toggle:** Seamless switching with persistent preference using `localStorage`.
- **📱 Fully Responsive Design:** Fluid layouts optimized across desktop, tablet, and mobile touch devices.
- **⚡ Fast & Lightweight:** Zero framework bloat—built using modular CSS variables and native vanilla JavaScript.
- **🔍 Filterable Projects Grid:** Real-time client-side project filtering by category (AI / ML, Web Applications).
- **🖼️ Interactive Dashboards Gallery:** Carousel slider displaying analytical Power BI dashboard visual models.
- **📊 GitHub Profile & Stats Card:** Open-source stats section displaying active repository metrics and tech stack highlights.
- **📄 Interactive Project Modals:** Deep-dive modal popups providing technical overviews, concepts, and live link routing.
- **📜 Standardized Certifications Section:** Symmetrical layout displaying credentials from JPMorgan Chase, Deloitte, Walmart Global Tech, and more.

---

## 🛠️ Tech Stack & Architecture

- **Markup & Structure:** HTML5 (Semantic elements, Accessibility tags)
- **Styling & Layout:** Modern CSS3 (CSS Grid, Flexbox, Custom Properties/Variables, Keyframe Animations)
- **Dynamic Logic:** JavaScript ES6+ (DOM Manipulation, Event Delegation, LocalStorage API, IntersectionObserver API)
- **Icons & Typography:** Font Awesome 6.7.2, Space Grotesk & Inter (Google Fonts)
